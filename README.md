# لعبة حرب بسيطة بـ Pygame

ده كود لعبة حرب 2D بسيطة باستخدام **Python + Pygame**.

## 🎮 فكرة اللعبة
- اللاعب (مربع أخضر) يتحرك يمين/شمال.
- يطلق رصاص (مستطيل أصفر) بالـ Space.
- أعداء (مربعات حمراء) ينزلوا من فوق.
- لو الرصاصة لمست العدو → يختفي.
- لو العدو لمس اللاعب → **Game Over**.

---

## ⚙️ المتطلبات
تحتاج Python (3.9 أو أحدث) + مكتبة Pygame.

التثبيت:
```bash
pip install pygame
```

---

## ▶️ طريقة التشغيل
1. نزّل المشروع أو انسخه.
2. احفظ الكود في ملف باسم:
   ```
   game.py
   ```
3. شغّل اللعبة:
   ```bash
   python game.py
   ```

---

## 🎮 التحكم
- ⬅️ ➝ التحرك لليسار.
- ➡️ ➝ التحرك لليمين.
- **مسافة (Space)** ➝ إطلاق النار.

---

## 📂 رفع المشروع على GitHub
1. أنشئ مجلد وضع فيه ملف `game.py`.
2. اعمل ملف `requirements.txt` واكتب فيه:
   ```
   pygame
   ```
3. افتح الـ Terminal داخل المجلد:
   ```bash
   git init
   git add .
   git commit -m "First Commit - Pygame War Game"
   ```
4. اعمل repo جديد على GitHub وخد الرابط.
5. اربط المشروع وارفعة:
   ```bash
   git remote add origin https://github.com/username/pygame-war.git
   git branch -M main
   git push -u origin main
   ```
